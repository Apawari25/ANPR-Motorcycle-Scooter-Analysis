# ANPR Analysis – Motorcycle and Scooter

## Project Overview
This project focuses on analyzing Automatic Number Plate Recognition (ANPR) results for Motorcycles and Scooters.

## Dataset Summary
- Total Cases: 148
- Motorcycle: 62
- Scooter: 86

## Analysis Performed
- Vehicle-wise case analysis
- Number plate recognition status
- Plate detection confidence analysis
- OCR confidence analysis
- Vehicle detection confidence analysis
- Consistency score analysis
- Data visualization and graphs
- Excel dashboard preparation

## Tools Used
- Python
- Pandas
- Matplotlib
- Excel
- Google Colab

## Key Findings
- Scooter cases showed higher average confidence scores than Motorcycle cases.
- No Plate was the most common recognition status for both vehicle types.
- OCR confidence scores were relatively low for both categories.

## Project Output
The project includes an analysis report, summary tables, graphs, and an Excel dashboard.
